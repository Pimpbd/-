Готовый лендинг для Tilda

1) Самый простой вариант: откройте файл tilda-block-inline.html, скопируйте весь код и вставьте в Tilda: Блок T123 / HTML-код. Картинки уже встроены внутрь кода.

2) Альтернативный вариант: загрузите изображения из папки assets в Tilda/на хостинг, затем используйте tilda-block-with-assets.html и замените пути assets/*.jpg на URL загруженных картинок.

3) index.html — обычная HTML-страница для предпросмотра в браузере.

QR-код сейчас является визуальной заглушкой. После публикации страницы замените его или ссылку на ваш реальный URL/квиз.
